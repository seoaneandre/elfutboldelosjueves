# Frontend - El Fútbol de los Jueves

Aplicación React para la gestión de usuarios, eventos y valoraciones de partidos de fútbol.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm start
```

La aplicación se abrirá en http://localhost:3000

## Compilación para Producción

```bash
npm build
```

## Características

- 👥 Gestión de usuarios (crear, ver, editar)
- ⚽ Crear y gestionar eventos (partidos)
- 🏆 Sistema de valoración entre jugadores
- 📊 Estadísticas de desempeño
